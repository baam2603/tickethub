# Kiểm tra W06 FE1

## Chuẩn bị

Dùng Node.js 22 trở lên, pnpm theo `packageManager` và PostgreSQL 16, Redis 7 từ Docker Compose. Cài bằng `pnpm install --frozen-lockfile`, sau đó chạy `pnpm build`. Khởi động API và web với cùng giá trị `JWT_SECRET` nếu cấu hình khóa riêng cho môi trường local. Khởi tạo dữ liệu bằng `pnpm db:migrate` và `pnpm db:seed`.

Dùng cơ sở dữ liệu kiểm thử riêng cho Playwright. Kịch bản tạo sự kiện và quyết toán thử qua API. Dùng tài khoản admin và ban tổ chức từ seed. Cài trình duyệt bằng `pnpm --filter @tickethub/web exec playwright install chromium firefox webkit` rồi chạy từ thư mục gốc:

```bash
pnpm --filter @tickethub/web test:e2e w06-admin.spec.ts --project=chromium
pnpm --filter @tickethub/web test:e2e w06-admin.spec.ts --project=firefox
pnpm --filter @tickethub/web test:e2e w06-admin.spec.ts --project=webkit
```

Có thể khởi động hai ứng dụng trong hai terminal từ thư mục gốc:

```bash
pnpm --filter @tickethub/api start
```

```bash
# Dùng khóa local đã cấu hình ở API để proxy Next.js xác thực cùng phiên.
JWT_SECRET="$(node --env-file=apps/api/.env -p 'process.env.JWT_SECRET')" \
  pnpm --filter @tickethub/web start
```

## UC10 và UC11

| Màn hình                        | Kiểm tra                                                                                                                                                                                                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/admin/moderation`             | Danh sách hồ sơ ban tổ chức và sự kiện chờ duyệt đến từ API Admin. Kiểm tra duyệt và từ chối, lý do từ chối, cùng thông báo lỗi khi bản ghi đã thay đổi.                                                                                                      |
| `/admin/events/control`         | Lọc sự kiện đã công bố hoặc đình chỉ, chuyển trang và tra cứu bằng UUID.                                                                                                                                                                                      |
| `/admin/events/[id]/control`    | Nhập lý do, sau đó nhập lại UUID để đình chỉ. Kiểm tra trạng thái, số đơn bị hủy, chỗ được giải phóng và nhật ký. Mở cùng một sự kiện ở hai cửa sổ để xác nhận thao tác sai phiên bản được API từ chối và giao diện tải lại. Khôi phục sự kiện chưa kết thúc. |
| `/admin/dashboard`              | Đối chiếu số liệu tổng hợp trước bộ lọc trạng thái và danh sách theo trạng thái với phản hồi API. Kiểm tra tất cả trạng thái sai lệch.                                                                                                                        |
| `/admin/dashboard?view=payouts` | Tạo lệnh bằng UUID sự kiện, tạm giữ có lý do, tính lại và phê duyệt. Kiểm tra số tiền so với phản hồi API và xác nhận lệnh đã chi trả không còn hành động.                                                                                                    |

Xác nhận hai bước của Kill Switch là cơ chế xác nhận thao tác trên giao diện. Nếu yêu cầu xác thực lại danh tính bằng OTP hoặc mật khẩu, BE1 cần cung cấp cơ chế xác thực bổ sung cho lệnh đình chỉ. Quyền thực hiện, kiểm tra phiên bản, cập nhật trạng thái và audit log do API xử lý. Lệnh phê duyệt chi trả hiện ghi nhận `PAID_OUT` trong hệ thống.

## Hiệu năng và trình duyệt

- Chạy Lighthouse chế độ mobile trên web production (`pnpm --filter @tickethub/web start`). Ghi điểm Performance, LCP, CLS, TBT và cấu hình đo. INP cần đo qua thao tác hoặc dữ liệu người dùng thực tế.
- Kiểm tra điểm mobile tối thiểu 85. So sánh ảnh LCP, số byte ảnh và JavaScript trước và sau thay đổi. Kiểm tra phần hero có trong HTML phản hồi đầu tiên và ảnh tối ưu có `srcset`.
- Kiểm tra Chrome, Edge, Firefox, Safari, Zalo và Facebook bằng trình duyệt hoặc thiết bị thực tế. Trên màn hình hẹp, thử điều hướng, cuộn bảng, xác nhận hai bước và thao tác chi trả bằng bàn phím hoặc cảm ứng. Playwright WebKit hỗ trợ kiểm tra engine, Safari và trình duyệt trong ứng dụng cần thử riêng.

### Kết quả trên môi trường cloud hiện tại

- Kiểm thử W06 với Chromium desktop và mô phỏng Pixel 7 chạy qua API thật.
- Lighthouse 13.6, preset mobile, trang chủ production. Ba lượt đo đạt 78, 89 và 87 điểm Performance. Trung vị đạt 87, LCP trung vị 3,3 giây và CLS tối đa 0,003. Lượt đầu có cache ảnh lạnh đạt 78, nên cần tiếp tục theo dõi lần tải lạnh sau khi triển khai.
- Môi trường chặn tải Firefox và WebKit từ CDN của Playwright. Edge, Safari thực và trình duyệt trong ứng dụng Zalo/Facebook còn chờ kiểm tra.
